# Telegram-бот для поиска ошибок ЧП

Бот помогает быстро найти расшифровку кода ошибки частотного преобразователя.

## Что умеет
- выбрать модель ЧП;
- выбрать тип события: **Alarm** или **Fault**;
- ввести код вручную;
- найти запись даже если пользователь ввёл:
  - полный код, например `A01006`;
  - только цифры, например `1006`;
  - код с пробелами или дефисами.

## Пример сценария
1. Пользователь нажимает `/start`
2. Выбирает `Siemens SINAMICS G120 CU250S`
3. Выбирает `Alarm` или `Fault`
4. Вводит `A01006` или просто `1006`
5. Получает описание, причину и рекомендуемое действие

## Установка
```bash
python -m venv .venv
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate

pip install -r requirements.txt
```

Создайте `.env` по примеру `.env.example`:
```env
BOT_TOKEN=ваш_токен_бота
```

## Запуск
```bash
python bot.py
```

## Структура базы
Все данные лежат в `data/errors.json`.

Для каждой модели ЧП задаются:
- `name` — название преобразователя;
- `categories.alarm` — список алармов;
- `categories.fault` — список аварий;
- `prefix` — буква категории (`A` или `F`);
- `items` — сами коды.

Пример записи:
```json
"A01006": {
  "description": "Firmware update for DRIVE-CLiQ component required.",
  "cause": "Для работы с Control Unit нет подходящей версии прошивки.",
  "action": "Обновить прошивку через commissioning software."
}
```

## Особенность поиска
Если пользователь уже выбрал раздел `Alarm`, бот сможет найти код:
- `A01006`
- `01006`
- `1006`

То же самое для `Fault`.

## Дальнейшее расширение
Можно легко добавить:
